Token Radar ranks 198 pre-token protocols by comparables-calibrated implied value — the median live-token market-cap-to-TVL ratio in each category, shrunk toward the snapshot-wide median — with a 7-step farm plan for each and a sortable, filterable dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
